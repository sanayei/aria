# User Guide Overview

ARIA is a local-first AI assistant designed for document management, email handling, and intelligent automation.

## Core Features

### 📄 Document Management
- Automated scanning and OCR
- Intelligent classification
- Semantic search
- Archive organization

### ✉️ Email Management
- Gmail integration
- Smart categorization
- Draft generation
- Email search

### 🌐 Web Interface
- Document browser
- User management
- Admin panel
- Tag system

### 🤖 AI Agent
- ReAct (Reason + Act) architecture
- Tool-based execution
- Conversation history
- Risk-based approval
